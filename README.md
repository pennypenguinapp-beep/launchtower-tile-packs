# LaunchTower Pixel Tile Packs — 3 Ready-to-Use 16×16 Sets

Three focused pixel tile sets for 2D games. Each pack is a single 256×192 px PNG sheet with an 8-color base palette plus an 8-color variant palette. Free for personal and commercial use.

## The Packs

| Pack | Theme | Variant | itch.io |
|---|---|---|---|
| 🌲 Forest | Ground, water, vegetation, paths | Night | [forest-tile-pack](https://launchtower.itch.io/forest-tile-pack) |
| 🏰 Dungeon | Stone, walls, torches, lava, spikes | Torchlit | [dungeon-tile-pack](https://launchtower.itch.io/dungeon-tile-pack) |
| ❄️ Winter Forest | Snow, ice, evergreens, frozen water | Twilight | [winter-forest-tile-pack](https://launchtower.itch.io/winter-forest-tile-pack) |

## Specs

- **Tile size:** 16×16 px
- **Sheet size:** 256×192 px (16 tiles wide × 12 tiles tall)
- **Format:** PNG, transparent background
- **Palette:** 8 colors base + 8 colors variant per pack
- **License:** Free for personal & commercial use, no attribution required

## How to Use

1. Download the PNG sheet from itch.io
2. Import into your engine (Godot, Unity, Phaser, Pygame, etc.)
3. Slice at 16×16 to get individual tiles
4. Swap to the variant palette for alternate lighting
